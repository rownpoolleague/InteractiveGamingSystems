Scoresheet Instructions

How to Use the Scoresheet

1. Selecting Teams

Choose your team, Opponent and Rosters load automatically.

2. Assign Lag Winner / Lag Loser

1st name tapped will open a box for setting Lag Winner, 2nd player tapped will open a box to set Lag Loser and begin match. This can be changed if the wrong players are chosen by tapping "Reset Match".

3. Add Player to Roster

You may click "Add a Player to Either Roster" at any time between match play. Enter name and click the team the player is to be added to. By default the player is a new 3. Please make any adjustments to both players HC's as needed using the + and - signs. (i.e. new player = race to 3 adjust opponent to 3)

4. Enter Total Match Innings

Hash is determined by TOTAL Innings - Safeties / Wins thus there is NO need for a game by game inning count
Use the + / – buttons to adjust the total inning count.

5. Enter Player Stats

Each player has the following stats:
- HC = Handicap - These are auto filled but adjustable in case of shooting a new player or clerical error.
- Wins = Games won
- Safeties = Defensive shots
- 8B = 8 on Break(no foul)
- B+R = Break and Run
- E8 = ANY 8 Ball error resulting in a loss of game.
- Coach Check Box = Check the box when a player takes a coach. Resets when the game is over.

7. Transfer

Creates a scannable QR code for scoresheet sharing. PLEASE USE YOU'RE PHONE CAMERA. Some QR APP readers insert AD's into your browser, you're scoresheet should be free of advertisements.

8. Notes

Clicking opens a box to leave the LO notes. Click again to close the box. All notes are transferred when submitting a match.

9. Timer

Clicking opens a pop up timer. Click the red X to close the timer.

10. History

Opens a dialogue with all match data submitted by your team for the current evening. Click "Current Scores" to see match data submitted by ALL TEAMS that evening.

11. Submit Match

Invisible until there is a match winner. Press “Submit Match” and wait. The scoresheet will clear and the rosters will become visible - you are ready to enter the next match data.

11. End of the Night

After Submitting you're last match all scoresheet data will reset for the following week. You're match results will be visible for 12hrs.
